# Timeless

Portfolio site for **Timeless** ([@timeless.aiart](https://www.instagram.com/timeless.aiart/) on Instagram, [@Timeless_aiart](https://x.com/Timeless_aiart) on X), an AI creative making cinematic characters and concepts.

A single static page: open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main`, root folder).

- `index.html`: the whole site (no build step, no dependencies)
- `art/`: posters and carousel images
- `video/`: web-ready clips, each under 15 MB

All artwork and videos © Timeless.
